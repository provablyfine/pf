Add per-grant max ttl session duration field

Enforce the grant's session TTL on shell and exec SSH sessions (sftp is not reachable
through `pf ssh` today). Certificates now carry the computed session deadline and a
connection id; a PAM hook installed by `pf openssh host-init` terminates the login once
the deadline passes. Requires systemd/logind on the host; hosts initialized before this
release need `host-init` re-run to pick up the PAM wiring.
