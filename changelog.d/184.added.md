End live sessions on request.
`pfa live terminate <id>` and the `pfat` live sessions screen do it.
It needs the new `terminate` permission of the `live` grant.
New tenants give it to the root role. Existing tenants must grant it by hand.
The server tells the host through the bastion, so hosts must run this release and be registered.
`pf bastion register` does not end host sessions itself. It leaves a request for the session reaper.
On Linux, `host-init` now starts a `pf-host-reaper` service for this, and the PAM hook records open sessions in `/run/pf/sessions`.
Hosts that were set up before this release must run `pf openssh host-init` again.
The host ends every session of the same certificate.
