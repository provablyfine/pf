End live sessions on request.
`pfa live terminate <id>` and the `pfat` live sessions screen do it.
It needs the new `terminate` permission of the `live` grant.
New tenants give it to the root role. Existing tenants must grant it by hand.
The server tells the host through the bastion, so hosts must run this release and be registered.
On macOS and Windows the host ends every session of the same certificate.
Hosts that were set up before this release must run `pf openssh host-init` again, to learn where to write the request.
