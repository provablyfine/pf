New `ssh` grant type replacing `ssh-shell`, `ssh-port-forwarding` and `ssh-command`. It names a set of capabilities (`shell`, `pty`, `user-rc`, `agent-forwarding`, `x11-forwarding`, `port-forwarding`) and a command list per username, so a grant adds capabilities, a boundary ceiling bounds them, and a deny removes exactly the ones it names — "deny agent forwarding" no longer requires denying the whole shell. `null` on any field means the whole axis: any username, all capabilities, any command. Nothing is implied: a grant of `shell` alone issues a certificate without `permit-pty`, so an interactive session needs `pty` listed explicitly.
