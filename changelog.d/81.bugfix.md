Boundary ceilings now cap SSH agent forwarding and X11 forwarding. A ceiling entry was previously evaluated with the same predicate as a grant, which only tested username membership, so `permit_agent_forwarding` and `permit_x11_forwarding` set by a role grant passed through any boundary unchecked. The same predicate also made those flags dead in a `denied_list`, where an administrator writing `permit_agent_forwarding: true` to deny forwarding got a silent no-op.
