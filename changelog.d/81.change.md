A caller holding both an `ssh-shell` and an `ssh-port-forwarding` grant for the same username now receives `permit-port-forwarding` on their shell certificate, where shell issuance previously hardcoded it off. The two grants describe one set of capabilities for one session, so they are now evaluated together.

Stored `ssh-shell`, `ssh-port-forwarding` and `ssh-command` grants are rewritten to `ssh` by a database migration. Upgrade `pfa` and `pfat` together with the server: the legacy grant types are gone from the API, so an older client can neither write nor read SSH grants.
